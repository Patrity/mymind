# Judge Implementation Plan (cycle 84, harness step 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every approval gets a rule floor + LLM verdict (advisory, streamed to the card/iMessage), Smart Approvals auto-runs high-confidence safe calls in workstreams, and an output guard taints runs whose untrusted tool results carry prompt injection.

**Architecture:** `packages/core/src/lib/agent/judge/` (rules, verdict, guard-rules, guard) used by `ai-tools.ts`'s approval path and result path; `judge` AI usage; `approval_verdicts` table; `approval-verdict` / `output_warning` run events; agent settings fields; UI on the approval card, tool parts and Settings → Bridget.

**Tech Stack:** `@mymind/core`, AI SDK v6 structured output, drizzle, worker bus, Nuxt UI, vitest, playwright-cli.

**Spec:** `docs/superpowers/specs/2026-10-12-judge-design.md`

## Global Constraints

- Auto-approve predicate (exact): `settings.judge.enabled ∧ surfaceEnabled ∧ verdict.recommendation==='approve' ∧ verdict.confidence ≥ settings.judge.confidence (default 0.9) ∧ !verdict.error ∧ ruleFloor ∉ {critical, deny} ∧ !(tool.outbound ∧ runTainted) ∧ nonce unchanged`. Surface defaults: workstreams **on**, chat **off**; headless (jobs/wakes) **never** auto-runs.
- Judge call: `judge` usage chain (empty → `reasoning`), tool-free, 60 s timeout; guard LLM call 15 s; guard LLM flag threshold confidence ≥ 0.7; guard LLM runs only when heuristics are suspicious or `guard==='web'` ∧ text > 2048 chars; LLM input truncated to ~12,000 chars.
- Verdict: risk `low|medium|high|critical`, recommendation `approve|review|deny`, confidence 0–1, ≤ 3 reasons ≤ 200 chars each. Malformed/timeout → `error`, treated as `review`.
- Verdict and guard reasons are model output — rendered as escaped text only; never logged with the approval `command` body (log `logSummary ?? command` rule from cycle 79 stands).
- A verdict that arrives after a human decision is recorded and changes nothing.
- Gates: typecheck, test, test:db, build + worker stage. Conventional commits, **no attribution trailers**. Commit first, then mutate, restore with `git checkout`; never `git stash`. Use `expect.stringMatching`, never a bare RegExp inside `toMatchObject`. Dev DB shared — own `MYMIND_BUS_NS`, clean rows. Kill only your own PIDs.

## Review Focus
1. **Auto-approval escape** — any path where a call auto-runs outside the predicate (tainted outbound, rule-critical, headless, nonce swap, judge error read as approve, chat when off).
2. **Judge injection** — untrusted content in the judge prompt not fenced; reasons rendered as markup; the judge's own output steering the run.
3. **Races** — verdict vs human decision vs chat 120 s timeout vs Stop; double resolution of one approval; verdict after cancel.
4. **Guard false positives/negatives** — benign pages tainting (taint is costly: outbound needs approval, sandbox loses network); obvious injections passing.
5. **Latency** — guard on every web read; judge on every approval delaying cards.
